# HandwerkAI Basis

Build the initial frontend structure for a SaaS product called HandwerkAI.

HandwerkAI is an AI employee platform for German heating, plumbing and HVAC businesses.

The platform will eventually allow a business owner to:

- create an account

- create their company profile

- configure their services

- define their service areas

- configure opening hours

- configure an AI employee

- view conversations

- view leads

- receive notifications

- manage their AI website chat widget

For this first stage, do NOT implement AI functionality, workflows, payments, CRM integrations, or external APIs.

Create only the basic SaaS application structure and navigation.

We need:

1. Login page

2. Registration page

3. Dashboard

4. Company Profile

5. AI Employee

6. Conversations

7. Leads

8. Settings

Use a clean professional German B2B SaaS design.

The application language should be German.

Use placeholder data only for now.

Do not create complex functionality yet.
